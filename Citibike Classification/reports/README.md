# Strategic Analysis & Reports

This directory contains the executive-level documentation and finalized statistical results for the Citibike User Classification project.

## Document Overview

### [Citibike Classification - Write Up.pdf](./Citibike%20Classification%20-%20Write%20Up.pdf)
**Format:** Technical Report (PDF)  
**Target Audience:** Project Stakeholders / Data Science Leadership  

This comprehensive report synthesizes the technical findings from the analysis into a strategic narrative. Key sections include:

*   **Executive Summary:** Overview of the 90.49% Annual Member concentration in short-duration trips.
*   **Methodology:** Discussion of the **Logistic Regression** and **Random Forest** frameworks used to classify user cohorts.
*   **Data Strategy:** Explanation of the **50/50 Undersampling** technique used to address class imbalance between Casual and Annual users.
*   **Strategic Recommendations:** Actionable insights based on the model's performance and behavioral triggers identified during feature engineering.

## Statistical Significance
The analysis documented here prioritizes model interpretability, ensuring that the results are not just predictive, but explainable for business decision-making. By focusing on variables like "Very Short" trip duration and cross-borough activity, the report identifies the specific behavioral thresholds that distinguish a loyal annual subscriber from a casual user.
